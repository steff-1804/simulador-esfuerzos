# Simulador de esfuerzos combinados

Aplicación web educativa para analizar una sección tubular rectangular
sometida a carga axial excéntrica y flexión.

## Uso en línea

El proyecto está preparado para publicarse mediante GitHub Pages.

Consulte `INSTRUCCIONES_GITHUB.md`.

## Archivos principales

- `index.html`: interfaz.
- `styles.css`: diseño visual.
- `app.js`: cálculos y funcionamiento.
- `.nojekyll`: publicación estática directa.
